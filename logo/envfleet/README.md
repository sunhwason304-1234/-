# EV FLEET / (주)엔드레스 로고

원본 로고 이미지를 그대로 벡터화한 파일입니다. 글자 모양(폰트)과 색상은 원본에서 그대로 가져왔고, 바꾼 부분은 없습니다.

외곽선은 깔끔하게 다시 정리했습니다. EV·FLEET는 직선과 꼭짓점만으로 다시 만들었고(기울기 통일, 윗선·밑선 정렬), 한글은 가로획·세로획을 정확한 수평·수직으로 맞추고 곡선(괄호, ㅇ, ㅅ, ㅈ)만 부드럽게 처리했습니다.

| 파일 | 용도 |
|---|---|
| `envfleet-logo.ai` | Illustrator 파일 (PDF 호환 AI). **파일 → 열기**로 바로 열립니다 |
| `envfleet-logo.svg` | 웹·범용 벡터 |
| `envfleet-logo.png` | 미리보기 (4배 해상도) |

## 구성 (레이어/그룹)
- **EV**: 녹색 그라데이션 `#004B35 → #008731 → #12B126 → #9AD433` (아래 → 위)
- **FLEET**: 네이비 그라데이션 `#011231 → #02244F → #07345F → #254084` (아래 → 위)
- **bar**: 네이비 `#0F3073` + 회색 `#C2C2C2`
- **company**: (주)엔드레스, 검정 `#000000`

모든 글자는 아웃라인(패스) 처리되어 폰트를 설치하지 않아도 됩니다. 색상 모드는 RGB이므로 인쇄할 때는 Illustrator에서 **파일 → 문서 색상 모드 → CMYK**로 바꾸세요.
