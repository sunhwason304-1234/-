# 파크나라 (PARKNARA) 로고

파크골프 샤프트 전문 브랜드 **파크나라** 로고 세트입니다.

## 콘셉트
- **P 모노그램**: 세로획은 샤프트(그립 → 테이퍼드 샤프트 → 클럽헤드), 둥근 획은 스윙 궤적, 가운데는 파크골프 공.
- **컬러**: 포레스트 그린 `#0E3B2C` (잔디·신뢰) + 골드 그라데이션 `#F2D27A → #D4A83A → #9C7420` (프리미엄).
- **서체**: Montserrat Black Italic (속도감), Black Han Sans (한글), Oswald (태그라인). 모든 글자는 아웃라인(path) 처리되어 폰트 설치 없이 사용 가능.

## 파일
| 파일 | 용도 |
|---|---|
| `parknara-logo.svg/png` | 기본 가로형 (밝은 배경) |
| `parknara-logo-dark.svg/png` | 다크 그린 배경용 |
| `parknara-logo-black.svg/png` | 단색(검정) – 각인, 팩스, 도장 |
| `parknara-logo-white.svg/png` | 단색(흰색) – 어두운 사진 위 |
| `parknara-emblem.svg/png` | 원형 엠블럼 – 샤프트 라벨, 스티커, 굿즈 |
| `parknara-icon.svg/png` | 앱 아이콘 / SNS 프로필 |

PNG는 2배 해상도로 렌더링되었습니다. 인쇄에는 SVG를 사용하세요.

## 재생성
`build.py`로 색상·문구를 수정해 다시 만들 수 있습니다 (`pip install fonttools`, `@fontsource/montserrat`, `@fontsource/black-han-sans`, `@fontsource/oswald` 폰트 패키지 필요, `FONT_DIR`로 경로 지정).
